Описание проекта
TaskFlow - это сервис для управления задачами, разработанный с использованием стека FastAPI. Проект позволяет создавать, просматривать и отслеживать задачи в асинхронном режиме. Основная цель проекта - демонстрация архитектурных подходов к построению REST API, работы с базой данных и интеграции с очередями задач.

Стек технологий

Язык: Python 3.14

Фреймворк: FastAPI

База данных: PostgreSQL

Очереди/Кэш: Redis

Контейнеризация: Docker & Docker Compose

Тестирование: Pytest + Httpx (асинхронное тестирование)

🛠 Установка и запуск
Клонируйте репозиторий:

Bash
git clone https://github.com/ВАШ_НИК/taskflow.git
cd taskflow
Настройка окружения:
Создайте файл .env на основе примера (если есть) и укажите переменные окружения для подключения к БД и Redis.

Запуск через Docker:

Bash
docker-compose up -d --build
Документация:
После запуска API будет доступно по адресу: http://localhost:8000/docs (Swagger UI).

Тестирование
Для запуска тестов внутри контейнера выполните:

Bash
docker-compose exec api pytest

Архитектурные решения

Асинхронность: Все эндпоинты реализованы через async/await, что позволяет эффективно обрабатывать множество запросов одновременно.

Тестирование: Использование ASGITransport для тестирования позволяет имитировать HTTP-запросы внутри памяти без поднятия реального сетевого интерфейса.

Контейнеризация: Использование docker-compose обеспечивает полную изоляцию инфраструктуры (БД, Redis, API).
